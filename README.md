# Yinhan (Lizzy) Gao — Academic Portfolio

Source for my [personal website](https://lizzy-g54.github.io/). I am an undergraduate studying Computer Science and Applied Mathematics at Duke Kunshan University and Duke University. My interests include human-computer interaction, human-centered AI, and affective computing.

## Research highlights

- **CollaDrum:** A tangible interactive music system designed to support collaboration among children with autism spectrum disorder. [CHI EA 2026 paper](https://doi.org/10.1145/3772363.3799088)
- **Multimodal emotion cause explanation:** Work on explaining emotions in dialogue using text, video, and conversational context. See the [research section](https://lizzy-g54.github.io/#research) for a summary.
- **Social sentiment visualization:** An interactive exploration of Reddit sentiment and GameStop market data. [Project repository](https://github.com/Lizzy-g54/GME-sentiment-analysis)

The website includes my publications, research projects, and experience. Research summaries describe my role; code or data are linked only where they can be shared publicly.
